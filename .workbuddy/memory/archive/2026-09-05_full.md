## ③ 调试方法学：MCP quit 后无数据
- **结论**：`mcp__godot__get_debug_output` 在进程 quit 后拿不到任何数据（"No active Godot process"）。
- **解决**：Bash `run_in_background` 启动控制台版 Godot → stdout/stderr 重定向
  `.workbuddy/logs/*.log` → `Read` 工具读日志。
- **证据**：`GODOT_PATH=C:/Users/lijia/Desktop/Godot_v4.7-stable_win64_console.exe`
  （写在 `~/.workbuddy/mcp.json`）。
- **指针**：沙箱内 PowerShell `Start-Process` 启动 detached GUI 进程**返回空**（exit 1），
  按工具说明本就不能用 PowerShell 启 GUI；这种场景一律走 Bash `run_in_background`。
  探针模板：`create_timer(1.5).timeout.connect(spawn×3 + probe)` + `create_timer(12).timeout.connect(quit)`，
  12s quit 必须早于客户端失去进程的窗口。

## ⑤ 闪红 SCRIPT ERROR 修复
- **根因**：MeshInstance3D（3D）**没有 `modulate` 属性**（modulate 只属 CanvasItem/2D）。
  我本能用 `body.modulate = Color(...)` → SCRIPT ERROR。
- **修法**：`enemy.gd _flash_and_free` 改 `body.material_override.albedo_color = Color(2.0, 0.4, 0.3)`。
- **验证**：`.workbuddy/logs/verify_death.log` 23 行，stderr 完全干净。
- **教训**：用 `wc -l` 先确认日志行数，不要凭 `Read` 视觉估计（Read 可能截断）。
- **嵌套 lambda 闭合**：`_ready` 里两层 `connect(func() -> void: ...)` 需要 **2 个 `)`**（每层 lambda 闭包一个）。
