## 屏幕全黑 → 根因是 ImageTexture 首帧尺寸不匹配
**根因**：`ImageTexture.new()` 是 0×0，首帧 `update()` 尺寸不符且**静默不更新**（不抛异常）
→ 表现"代码全对、屏幕永远全黑"。修：尺寸不符走 `set_image()`（首帧一次），之后 `update()`。
顺带修 Parse Error：`sv.get_image()` 静态类型推不出（Variant → 触发"警告即错误"）→
改走 `get_texture().get_image()` + 显式 `var img: Image`。
→ 5 条出图坑全表见 `monitor_feed.md §出图链路与坑`

## 白板回潮 → 自发光覆盖才是真凶
用户报"不要加亮光覆盖 viewporttexture"。根因：我上一轮把 `screen_material` 默认写成
`emission_enabled:true + emission:[1,1,1]`，把 95% 黑的暗 feed 洗白 —— 用户上午定的
"emission 调 (0,0,0) 才显示原始画面"没保住。改回 `false + [0,0,0]`，诊断加"无自发光覆盖OK"。
试过"预填黑图防闪白"→ `Image.create_black` 不存在 / `get_format()` 返回 GPU 格式(47) → 此路不通，撤掉。
验证：主截图彩色标记像素 **13%**、均值亮度 0.0615（emission 开时 0.1497）→ 无白板。
