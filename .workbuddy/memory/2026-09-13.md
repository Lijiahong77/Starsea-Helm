## 接管视角架构登记 · DEC-050（李拍板：**只登记、不实现**）

- 李的三条诉求看似三件事，实为**同一件事**：**炮塔没有「骨架」**。
  ① 开火从屏幕中心（相机挂 `Player` 子节点、偏移写死**世界 Y** +1.6 m → 左右舷/底炮视角飘）；
  ② 炮塔无「我朝哪个面」的概念（BoxMesh 永远朝 +Z，所以谈不上射界）；
  ③ 炮塔不跟视角转（只转相机，炮塔模型一动不动）。
  **地基已有**：`turrets.json` 每门炮的 `axis` **就是船壳外法线**，只是没被当法线用。
- **四条决策**：① 关节骨架 `MountPoint(法线对齐 axis) → YawPivot → PitchPivot → 炮身 / 炮口 / 相机挂点`；
  ② 射界 = **每门炮只管自己那一面的半球**（偏航绕法线 360°、俯仰 0°→90°）—— 顶炮天然打不到船底，**无需逐面写规则**；
  ③ 相机 **后上越肩**（沿炮管后 1.2 m + 沿法线 0.8 m，李选 B）；④ 视角比炮塔**多扭 ±10~15°**、炮塔到极限停住（让玩家看得见「够不着」）。
  主炮 `fore` **不参与**（玩家在舰桥内透过舷窗打正面）。
- ⚠ 实现时必须加 `Turret.acquire_target()` 的**「射界内」过滤** —— 否则自动炮会锁住自己打不到的目标，
  表现 = 对着极限角干转、敌人血不掉（与 DEC-049 `is_engaged` **同类**：不报错但全船哑火）。
- **推迟理由**：真船体一改，法线 / 炮位可能全变 → 现在按白盒方块搭的骨架要返工。
  落地顺序（一次一步）：骨架 → 射界夹取 → 相机越肩+略宽 → 锁敌射界过滤。
