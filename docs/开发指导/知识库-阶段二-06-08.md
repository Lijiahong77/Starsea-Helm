## 第 06 课：用 AI 产出全套视觉资产

### 两条路：本地 vs 在线
| 路径 | 工具 | 硬件需求 |
|------|------|---------|
| 本地 | Stable Diffusion / ComfyUI | 12GB+ 显存 |
| 在线 | Midjourney / NovelAI | 无硬性要求，联网即可 |

### 美术资产清单（弹珠肉鸽示例）
| 资产 | 尺寸 | 格式 |
|------|------|------|
| bg_pinball_table（背景板） | 1920×1080 | PNG |
| ball（弹珠） | 128×128 | PNG |
| peg（图钉） | 64×64 | PNG |
| launcher（发射器） | 128×192 | PNG |
| pocket（奖励袋洞） | 256×256 | PNG |
| ui_panel（面板） | 640×480 | PNG |

### 统一样式 Prompt（关键）
```
flat cartoon style, pinball machine theme, bright colors,
simple shapes, no complex details, game asset, transparent background
```

### 角色一致化方案
1. **三视图**：正面 / 侧面 / 背面
2. **LoRA 训练**：20–30 张图，500 steps
3. **测试**：用训练好的 LoRA 生成新图

### 资产交付标准
| 项目 | 规范 |
|------|------|
| 命名 | `type_prefix_description.png`，统一 lowerCamelCase 或 snake_case |
| 尺寸 | 2 的 n 次幂对齐（128/256/512/1024） |
| 格式 | 游戏场景 PNG / UI PNG / 图标 SVG |
| 目录 | assets/sprites / assets/ui / assets/icons |

### 版权注意
- AI 生成作品的版权仍有争议
- Midjourney：付费计划含商业授权
- Stable Diffusion：开源但需确认模型协议
- 商用需谨慎

### 工作流
```
列出资产清单 → 逐个生成 → 对照交付标准检查 → 统一样式 → 整理命名
```

## 第 07 课：用 AI 做主视觉与短片

### 主视觉（Key Visual）三要素
1. **主体**：弹珠命中图钉 + 粒子爆发
2. **构图**：主体居中 + 周围装饰元素
3. **风格**：与游戏美术统一

### 短视频两条路
| 路径 | 工具 |
|------|------|
| AI 生图 + 剪辑 | Midjourney 出图 + 剪映剪辑 |
| 实机录制 | 直接录实际玩法画面 |

### 15 秒短视频结构
```
0–3s  hook（快节奏球碰撞）
  ↓
3–8s  玩法展示（核心循环）
  ↓
8–12s 高光时刻（Fever / 大数字弹出）
  ↓
12–15s CTA（标题 + 口号）
```

### 30 天推广排期
| 天数 | 内容 |
|------|------|
| D1 | 发布视频 |
| D3 | 主视觉 + 游戏截图 |
| D7 | 15 秒竖版短视频 |
| D14 | 更新日志 |
| D21 | 玩家反馈收集 |
| D28 | 数据复盘 |

### 平台尺寸
| 平台 | 比例 |
|------|------|
| Bilibili | 16:9 |

## 第 08 课：用 AI 优化关卡与策划

### 三档难度
| 关卡 | 图钉密度 | 袋洞数量 | 时间限制 |
|------|---------|---------|---------|
| 热身关 | 少 | 多 | 长 |
| 普通关 | 标准 | 标准 | 标准 |
| Boss 关 | 密 | 少 | 短 |

### 核心原则：难度曲线"先慢后快"
- 前期给玩家正反馈，建立信心
- 后期引入压力，制造"还有机会翻盘"的紧张感

### 关卡设计可调参数
| 参数 | 含义 |
|------|------|
| ball_spawn_position | 弹珠生成位置 |
| peg_density | 图钉密度 |
| pocket_position | 袋洞位置 |
| time_limit | 时间限制 |
| ball_count | 起始球数 |

### AI 在关卡设计中的角色
1. **生成关卡布局**：根据参数自动生成图钉阵
2. **模拟弹珠轨迹**：预测球的运动路径
3. **分析难度曲线**：根据数据建议调整
4. **提出优化建议**：增减图钉、调整袋洞位置

### 数据驱动迭代
```
第一版白盒关卡 → 调数值 → 试玩 → 数据反馈 → AI 分析 → 迭代
```

### 关键指标
- **成功率**：多少比例的玩家能通关
- **平均得分**：反映难度合理性
- **常见失败点**：哪些位置最容易卡住
