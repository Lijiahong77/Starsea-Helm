# MVP 范围声明
> 按知识库第 05 课产出物建立。最后更新：2026-09-01（**第三轮重定位对齐**）
> **AI 帮你排优先级，但拍板在人类。** 本文件是你拍板的结果。

---

## 一、三个里程碑（顺序不能反）

| 术语 | 回答的问题 | 长什么样 | **本项目的验收标准** |
|------|-----------|---------|-------------------|
| **Prototype** | 技术上做得出来吗？ | 美术全色块，可能没有完整循环 | ① 能转头看的白盒主控室（第一人称，仅艏部单面舷窗）<br>② 六扇区敌人来袭并被击毁<br>③ 主炮固定正面开火 + 副炮×4 向自动开火；玩家可接管任一炮塔提速<br>④ 炮塔有耐久、能被摧毁；**所有炮塔被毁 = 本局失败**<br>⑤ 监控以**副炮视角切换**实现，能用<br>⑥ 帧率 ≥ 55 |
| **MVP** | 核心循环好玩吗？ | 白盒 / 占位图，完整闭环 | ① 完整闭环：装配 → 战斗 → 调整装配 → 战斗（危机为单位）<br>② 朋友玩 3 分钟还想再玩<br>③ 五条验证指标达标（见 `EXPERIENCE.md`） |
| **Vertical Slice** | 玩家会买账吗？ | 某一段用最终品质，5–15 分钟可玩 | 「前 N 危机」这一段达到最终美术与音效品质，可拿去给人看 |

> MVP 是一个**商业可行性假设**，Prototype 不是。先 rapid prototyping，再 polish。

## 二、MVP 范围声明（5 行）

```
做：六扇区围攻 + 主炮固定正面 + 四向副炮（可多门、可接管）的据点防守
做：波次间改装（换炮塔类型 / 扩展槽位），这是主玩法，无时间限制、无货币
做：随危机进度自动解锁更强炮型，成长感不靠攒钱
做：监控以副炮视角切换为主（雷达仅作性能退回），补全舷窗外的战况
做：完整闭环 —— 装配 → 战斗 → 调整装配 → 战斗
不做：能源、弱点、三选一构筑、剧情、角色、多人、存档、成就、VR、战术指令（Prototype）
```

## 三、Prototype 阶段必须验证的三件事

> 知识库第 05 课：Prototype 只回答「技术上做得出来吗」。
> 但本项目有三条**设计假设**如果错了，后面全白做 —— 所以要在 Prototype 阶段一并验证。

| # | 假设 | 怎么验证 | 错了怎么办 |
|---|------|---------|-----------|
| **P-1** | 「主炮固定 + 副炮可接管」能撑起战斗阶段的乐趣 | 白盒跑通后自己玩 10 危机，感受「接管哪门炮」是否有张力 | 若无感 → 调整手动/自动 DPS 差距（见 `03_rules.md` `manual_dps` vs `auto_dps`） |
| **P-2** | 监控（副炮视角）真的让玩家不得不切着看 | 自己玩时记录视线：有没有主动切到副炮视角 | 若全程盯舷窗 → 缩小舷窗视野（调 `viewport_width`/`console_distance`）/ 提高非前方来袭比例 |
| **P-3** | 低 APM 战斗不会无聊（随机 vs 认真装配） | 认真配装 vs 随机装配，比较撑过的危机数 | 若差距 < 3 危机 → 反例 2 触发，需重新设计决策权重 |

> **P-3 是最关键的一条。** 它验证的不是技术，是整个立项假设（DEC-021）。

## 四、明确不在 MVP 内（防止范围蔓延）

| 项 | 优先级 | 何时做 |
|----|--------|--------|
| 能源系统 | ❄️ 搁置 | 模块 > 12 个且槽位约束不足时（DEC-022） |
| 剧情 / 角色 / 配音 | P3 | Vertical Slice 之后 |
| 跨局永久解锁 / 元进展 | P2 | MVP 验证通过后 |
| 多人 / 联机 | P3 | 不做 |
| 存档 / 成就系统 | P2 | MVP 只存「最高危机数」一个数字 |
| 舰桥内自由走动 | P3 | VS 阶段 |
| VR 实装 | P3 | 另行立项 |
| 战术指令 / 主动技能（含防御盾） | P2 | MVP 验证通过后（DEC-035） |
| 敌人类型化进攻偏好（围攻 / 游击） | P2 | MVP 后（Q12） |

## 五、MVP 时间盒

> 知识库第 01 课三问法之三：**2 周内能做完吗？**

| 阶段 | 目标工作量 | 说明 |
|------|-----------|------|
| Prototype | **3 – 5 天** | 白盒，只验证技术与三条设计假设 |
| MVP | **≤ 2 周**（从 Prototype 通过后计） | 知识库给的 MVP 开发周期经验值 |

**如果 Prototype 超过 5 天还没跑通 → 停下来砍范围，不要硬做。**
