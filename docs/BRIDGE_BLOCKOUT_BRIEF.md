# 主控室 Blockout 任务书（Blender 白盒草稿）

> 用途：交给 Blender Agent，用**最简单的基础几何体**搭出主控室的空间草稿。
> 目标只有一句话：**把"房间多大、每样东西在哪"确定下来**。不要材质、不要细节、不要倒角。
> 单位：**1 Blender 单位 = 1 米**（保持默认，不要改缩放）。

---

## 一、坐标系（先读这条，最容易错）

- Blender 是 **Z 轴朝上**。
- **舷窗（房间"前方"）朝 Blender 的 `-Y` 方向** —— 也就是按 Numpad 1（Front 视图）时，你正面看着舷窗。
  - 这样导出 `.glb` 后，Blender 的 `-Y` 会自动映射成游戏引擎（Godot）的 `+Z`，正好是"船头方向"，**不用再手动旋转**。
- **原点 `(0,0,0)`** = 房间地板面，位于房间前后 / 左右的正中央。
- 三轴含义：

| 轴 | 方向 | 范围 |
|---|---|---|
| **Z** | 高度（地板→天花板） | `0` → `3.0` |
| **X** | 左右（`-X` 左舷 / `+X` 右舷） | `-2.5` → `+2.5` |
| **Y** | 前后（**舷窗在前 `-Y`**，舱门在后 `+Y`） | `-3.0` → `+3.0` |

---

## 二、房间本体（净空尺寸，不含墙厚）

| 方向 | 内部范围 | 净尺寸 |
|---|---|---|
| 宽（X） | `-2.5` → `+2.5` | **5.0 m** |
| 深（Y） | `-3.0` → `+3.0` | **6.0 m** |
| 高（Z） | `0` → `3.0` | **3.0 m** |

> ⚠️ **高度就是 3.0 m，不要做成"真正的立方体"。** 这个房间是「宽而矮」的——3 m 层高在 5×6 的房间里会形成**明显的压迫感**，这是故意的。做成 6 m 高的方形厅，压迫感立刻消失。

**六面墙**（墙厚统一给 0.2 m，往内墙面的外侧长）：

| 面 | 位置 | 说明 |
|---|---|---|
| 地板 | `Z = 0` | 5.0(X) × 6.0(Y) |
| 天花板 | `Z = 3.0` | 5.0(X) × 6.0(Y) |
| 左墙 | `X = -2.5` | 6.0(Y) × 3.0(Z) |
| 右墙 | `X = +2.5` | 6.0(Y) × 3.0(Z) |
| **前墙** | `Y = -3.0` | **只有这一面开窗**（见第三节） |
| **后墙** | `Y = +3.0` | 实心 + 一扇舱门（见第六节） |

> ⭐ **核心约束：只有前墙有窗，其余五面全是实心墙。**
> 玩家能 360° 自由转身，但转身只能看到舱壁——这是整个游戏的核心设计（信息不对称）。
> **千万不要手滑做成"四面玻璃"或加第二扇窗。**

---

## 三、前墙的舷窗（唯一一扇窗）

在 `Y = -3.0` 这面墙上，开一个矩形窗洞：

| 项 | 值 |
|---|---|
| 窗洞宽（X） | **4.4 m**（X 从 `-2.2` 到 `+2.2`） |
| 窗洞高（Z） | **1.30 m**（Z 从 `0.95` 到 `2.25`） |
| 窗台高 | **0.95 m**（窗洞下沿离地高度） |

- **窗洞四周是实心墙**：
  - 下方墙：`Z 0 → 0.95`
  - 上方墙：`Z 2.25 → 3.0`
  - 左右两侧墙条：各 0.3 m 宽（`X -2.5→-2.2` 和 `X +2.2→+2.5`）
- **窗框**：在窗洞四周加一圈"加强梁"（细长立方体，截面约 `0.1 × 0.1`，向舱内凸出约 `0.05`），共 **4 根**（上 / 下 / 左 / 右）。这是"这是一扇窗"的视觉提示。
- **玻璃**：一块 `4.4 × 1.30`、厚 `0.02` 的薄板，放在 `Y = -3.0`。占位即可（先给个半透明材质表示是玻璃）。

---

## 四、控制台（玩家正前方）

玩家站在房间里、面朝舷窗（朝 `-Y`）。控制台位于**玩家与舷窗之间**。

**玩家眼位（参考点）**：`(0, -1.3, 1.60)`
→ 离舷窗玻璃 `1.7 m`，眼高 `1.6 m`。
（可以在这一点放一个小立方体、命名 `Ref_PlayerEye`，方便对位置。）

### 4.1 控制台主体

| 项 | 值 |
|---|---|
| 宽（X） | **2.6 m**（`-1.3` → `+1.3`） |
| 深（Y） | **0.6 m**（`-2.2` → `-1.6`） |
| 高（Z） | **台面 0.95 m**（方块从 `0` 到 `0.95`） |

> 形状是**弧形**，但白盒阶段**先用一个长方体**就行，不要费劲做弧。
> 台面离地 0.95 m 是"人手扶着舒服"的高度，别改。

### 4.2 监控面板（4 块屏）

4 块小方块，**2×2 排布**，装在控制台台面中央偏上、**朝玩家斜上**。

| 项 | 值 |
|---|---|
| 单块屏 | **0.5（宽）× 0.375（高）**，厚 `0.03` |
| 4 块间距 | 横竖各留 `0.05` 缝 |
| 整组尺寸 | 约 `1.05（宽）× 0.80（高）` |
| 位置 | 屏幕组中心 ≈ `(0, -2.0, 1.05)` |
| 朝向 | 屏幕**顶边比底边更靠舷窗（离玩家更远）**，整面从竖直向后仰约 **30°**（这样玩家低头就能平视它） |

> 4 块屏分别对应左舷 / 右舷 / 上极 / 下极四门副炮的实时画面。白盒阶段用 4 个扁方块区分就行。

### 4.3 操作面板（飞船操作开关）

屏幕**两侧**各一块（也可再多），扁的斜面板贴在台面上：

| 项 | 值 |
|---|---|
| 单块 | 约 `0.6（宽）× 0.35（深）`，厚 `0.04` |
| 位置 | `X = ±0.85`，`Y ≈ -1.85`，`Z ≈ 0.99` |
| 朝向 | 与控制台台面同角度（后仰约 30°） |

> 这两块是"飞船操作面板"（开关 / 按钮 / 拨杆的集中区），和屏幕区分开。

## 五、座椅（玩家身后）

| 项 | 值 |
|---|---|
| 位置 | 玩家眼位正后方，`Y ≈ -0.5`（离玩家约 0.8 m），`X = 0` |
| 座面 | `0.5（X）× 0.5（Y）`，座面高 `Z = 0.45` |
| 靠背 | `0.5（X）× 0.6（Z）`，位于座面后方，顶到 `Z ≈ 1.1` |
| 朝向 | 面朝舷窗（朝 `-Y`） |

> 座椅是**装饰件**（玩家实际站位操作），白盒阶段一个"座面 + 靠背"两个方块就够。

---

## 六、后墙 + 舱门

- 后墙在 `Y = +3.0`。
- **舱门**：居中，宽 **1.2 m**（`X -0.6` → `+0.6`）、高 **2.1 m**（`Z 0` → `2.1`）。
  - 用一个薄方块（厚 `0.1`）嵌在墙上、向舱内凸出一点表示门扇。
- 门左右两侧（到 `X = ±2.5`，各约 `1.3 m` 宽）可放壁柜（见下节）。

---

## 七、道具（少放，别塞满）

房间要"紧凑、压抑"。道具**点到为止**，塞满了就变成杂物间。

| 道具 | 位置（近似） | 尺寸（X×Y×Z） |
|---|---|---|
| 舱门两侧壁柜 ×2 | 贴后墙 `Y = +2.85`，`X = ±1.6` | `0.7 × 0.3 × 1.8` |
| **后左角储物箱** | `X = -2.0`，`Y = +2.4`，贴地 | `0.8 × 0.8 × 0.8` |
| 天花板横梁 ×3 | `Z = 2.85`，横跨 X 全长，Y 均布 | `5.0 × 0.15 × 0.2` |
| 顶灯 ×2 | `Z = 2.92`，`X = ±1.2`，`Y = -1.5` | `0.7 × 0.7 × 0.06` |
| 左右墙管线 | 贴墙 `X = ±2.42`，`Z ≈ 2.5`，沿 Y 走向 | 圆柱 ⌀0.15，长 5.0 |

> "左下角"这里按**后左角**（出舱门那侧、进门左手边）理解——放一个储物箱。

## 九、搭建顺序 & 方法建议

**按这个顺序搭，每步确认无误再下一步：**

1. **搭壳**：地板 + 天花板 + 4 面墙，先全部做成实心方块，确认 `5.0 × 6.0 × 3.0` 的盒子尺寸对。
2. **挖窗**：前墙**用 4 个方块拼**（窗下墙 / 窗上墙 / 左墙条 / 右墙条）——
   **不要用布尔运算挖洞**，直接 4 块拼更干净、后期更好改。
3. **放窗框 ×4 + 玻璃**。
4. **放玩家参考点小方块 + 控制台 + 4 块屏 + 2 块操作面板**。
5. **放座椅、后墙壁柜、舱门**。
6. **最后加道具**（横梁 / 顶灯 / 管线 / 储物箱）。
7. **导出** `File → Export → glTF 2.0 (.glb)`，保持默认的 **Y Up** 勾选。

**组织方式：**

- 每个物体**单独命名**（`WallFront_Below` / `Console` / `Screen_01` / `CeilingBeam_01` …），方便后面单独替换或调整。
- 建议归类到 collection：`Room_Shell` / `Window` / `Console` / `Props`。
- **不要把所有东西合并成一个 Object** —— 保留独立对象。
- 左右对称的部件（墙条 / 壁柜 / 顶灯）可只做一侧，再用 Mirror 镜像。

**心态：这是草稿，不是成品。**
目的是"看一眼就知道空间关系对不对"，所以**越简单越好、搭得越快越好**。

---

## 十、硬约束 / 禁止事项（照抄，别发挥）

1. **尺寸照抄，不要"感觉差不多"就改数** —— 每一个数字都和别的设计挂钩（比如窗宽影响视野角、层高影响压迫感）。
2. **不要加第二扇窗、不要改窗的位置**。
3. **不要改房间尺寸，尤其不要把层高做大**。
4. **不要做材质、倒角、面数细分、UV** —— 白盒不需要。
5. **不要用布尔运算挖窗洞**。
6. **不要合并对象**。
7. **有任何不清楚的地方，先问，不要自己猜。**

---

## 十一、交付物

- 一个 `.glb` 文件（保持比例，1 单位 = 1 m）。
- 建议导出一张**俯视图 + 一张从舷窗向外看的视角图**（截图即可），用来核对空间关系。
