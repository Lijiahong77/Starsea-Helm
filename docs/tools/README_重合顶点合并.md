# Blender 重合顶点合并工具

> 2026-09-14 · 用于修复"重复导入"造成的虚焊网格（visually welded / topologically split）

## 问题是什么

飞船模型被**重复导入**（从网站多次导入、或导入时被拆开再合并）后，同一位置会出现**多个独立顶点**：

- 视觉上完全重合，看起来是一个点；
- 拓扑上是分开的 —— 边和面在这一点"虚焊"；
- 后果：法线分裂（着色有缝）、导出后网格体积膨胀、布尔/倒角/细分出问题、Godot 里非水密（若做布尔或碰撞会踩坑）。

这叫 **重合顶点（doubles / duplicate vertices）**，Blender 的修法是 **Merge by Distance**（合并按距离）。

## 工具在哪

| 文件 | 用途 |
|------|------|
| `blender_merge_doubles.py` | **独立脚本版**，丢进 Blender 的 Scripting 跑一次 |
| `blender_merge_doubles_addon.py` | **插件版**，装进 Blender 常驻，右侧 N 面板出「网格修复」按钮 |
| `_verify_merge_algo.py` | 算法自检（纯 Python，不需要 Blender），验证过的边界情况都记录在这 |

## 怎么用

### 独立脚本版（推荐首次使用）
1. Blender → 顶部 **Scripting** 工作区。
2. **Open** → 选 `blender_merge_doubles.py`。
3. 回到 3D 视图，**选中要处理的物体**（可多选）。
4. 回到 Scripting 点 **Run Script**（或 `Alt+P`）。
5. 看底部 Console 输出：`顶点 X → Y（合并 Z，共 N 轮）`。

### 插件版（推荐反复使用）
1. Edit → Preferences → Add-ons → **Install…** → 选 `blender_merge_doubles_addon.py` → 勾选启用。
2. 3D 视图右侧按 **N** → 出现「网格修复」标签页。
3. 选中物体 → 先点 **预览（Dry Run）** 看会合并多少，再点 **合并重合顶点**。

## 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| **合并距离** | `0.0001 m`（0.1 mm） | 距离小于该值的顶点被合并。**默认只吃"几乎完全重合"的点**，不会误伤正常细节 |
| **最大轮数** | 20 | 复查循环上限，防死循环；正常 2~3 轮收敛 |

**什么时候调大合并距离**：
- 若模型是**从网站导入时被整体缩放过**，重合点可能差几毫米 → 试 `0.001`（1 mm）。
- ⚠ **不要盲目调大**。合并距离过大 = 会**误焊接本不该焊的点**（例如一块薄板的两个面、密集的螺丝纹理）。**宁小勿大，先预览**。

## 算法说明（为什么不是简单两两合并）

你的直觉对了一半：merge 在 UI 上是"两两"语义（要指定 First/Last），而且要能处理**3 个甚至更多点重合**的情况。

但**手写"两两合并 → 复查 → 再合并"的循环有致命坑**：

> **合并一个点会让 Blender 的顶点索引失效。** 第二轮若还引用旧索引，就会合并到**错误的点**上 —— 而且 Blender **不报错**，表现为网格被悄悄搞坏。这是最难查的一类 bug。

所以本工具的写法是：
1. **内层**：用 `bmesh.ops.remove_doubles(bm, verts, dist)` —— 它**一次处理 N 个重合点**（内部按距离空间分组），不管同位置是 2 个还是 10 个，一把融合。
2. **外层**：保留**复查循环** —— 直到某轮"顶点数不再减少"才停。原因：偶尔会有"三重重合先合掉两个"的情况，需要再跑一轮把剩下的也合掉。

**合并到哪个位置**：`remove_doubles` 合到**组内第一个顶点**的位置（At First）。对"重复导入造成的几乎完全重合点"，合到哪儿差异在浮点误差级，肉眼不可见 —— 所以 **At First / At Last 无所谓**，你说的没错。若想要"组内平均位置"，独立脚本版有 `USE_CENTER = True` 开关（默认关）。

|------|------|

| **单点四重/五重重合** | ✓ |
| **链条式桥接**（A-B 近、B-C 近、A-C 远，靠 B 桥接） | ✓ |
| 两簇各多重（不该跨簇合并） | ✓ |
| 无重合（不动） | ✓ |

| 合到首点（验证 At First 语义） | ✓ |

## 安全提醒

- **先备份**：脚本直接改 `obj.data`。Blender 里 **Ctrl+Z 可撤销一次运行**，但跑之前建议先 Save 一个副本（`File → Save As`）。
- **先预览**：插件版的 Dry Run 就是干这个的 —— 看数字对不对再动手。
- **这不是 Godot 那套"变换清除"**：合并顶点清的是"拓扑重复"，和 `docs/art/3D导入导出规范.md` 里说的 Apply Transform（清"节点变换"）是**两件事**，都要做。
  - 顺序建议：**先合并顶点（本工具）→ 再 Apply Transform → 再导出 .glb**。
