## 阶段状态机（GameStateManager）

```
        ┌─────────┐
        │  MENU   │
        └────┬────┘
             │ 开始航行（同一艘船）
             ▼
   ┌───────────────────┐
   │      REFIT        │◄──────────────┐
   │  （装配 · 主玩法）  │               │
   └─────────┬─────────┘               │
             │ 玩家确认                  │
             ▼                          │
   ┌───────────────────┐                │
   │      BATTLE       │                │
   │  （一波危机）      │                │
   └─────────┬─────────┘                │
             │ 本波敌人清空              │
             ├──────────────────────────┘
             │ 全部炮塔被摧毁
             ▼
   ┌───────────────────┐
   │      RESULT        │
   │  （本局结束 · 退回装配重打）│
   └─────────┬─────────┘
             │ 再来一次（同一艘船，保留解锁进度）
             └─────────────────────────► REFIT
```

> **循环单位 = 危机**（一波来袭 + 一次休整），不是「开一局」。
> 失败或想重来 → **退回装配界面重打同一艘船，不换船**，保留已解锁进度（培养长期归属感）。

| 状态 | 进入条件 | 玩家能做什么 | 退出条件 |
|------|---------|------------|---------|
| `REFIT` | 局开始 / 危机清空 | 装配炮塔类型与装备、预判下一波压力 | 玩家点击「进入战斗」 |
| `BATTLE` | 玩家确认 | 扫视（切副炮视角/看雷达）、接管某炮塔手动提速 | 敌人清空 → REFIT；全部炮塔被摧毁 → RESULT |
| `RESULT` | 全部炮塔被摧毁（**演出走 DEC-043 L3 终局**：夺玩家操控 + 镜头运动 + 敌舰包围 + 宣告 → 进 RESULT） | 查看成绩（撑过危机数 / 击杀）、再来一次 | 点击「再来一次」 |

## REFIT 阶段（主玩法 · 详细）

> **这是本作 70% 乐趣所在。无时间限制，不催促。**
> 📌 **REFIT 入场演出已落地（DEC-041，2026-09-08）**：清空一波 → 飞往维修站 →
> 维修师报告（纯氛围台词，**不涉钱**）→ 改装台换炮 → 出发。详见 `04_presentation.md §十`。
> 过场可跳过但**不给按钮**：任意键补完当前阶段；改装台阶段不吞键（那是玩法）。

| 步骤 | 内容 | 决策点 |
|------|------|--------|
| 1 | **战损复盘**：上一波哪门炮被点掉了、哪面压力大（**数据由 ⑨a 战损报告提供，DEC-043 一套数据四出口：主控室/维修站/维修师台词/改装台**） | 下一波该不该换炮型 / 加炮 |
| 2 | **装配炮塔**：换不同类型/级/功能的炮塔（速射/重炮/散射/对空/对重甲/范围…） | 装哪个、拆哪个 |
| 3 | **扩展槽位**：随进度解锁更多槽位，装更多炮 / 装备 | 广度 vs 专精 |
| 4 | **读预警**：下一波来袭面与规模预告 | 据此调整配置 |

**解锁驱动**：危机进度（累计度过的危机数）自动解锁，无货币、无残骸、无蓝图收集。

**成长方向**（取代旧「填洞」式成长）：
- 解锁**不同类 / 不同级 / 不同功能**的炮塔
- **扩展槽位数量**（装得更多 = 更能扛）

## BATTLE 阶段细分（一波危机）

| 子阶段 | 发生什么 | 玩家在做什么 |
|--------|---------|------------|
| **预警** | 雷达显示各面来袭规模与类型 | **扫视**雷达，预判哪面压力大 |
| **接敌** | 敌人进入射程，各炮塔自动射击（慢） | 必要时**接管**压力最大的炮塔手动提速 |
| **交战** | 主力交火，敌人开始攻击炮塔耐久 | 切副炮视角**看**别处、继续接管 |
| **清场** | 残敌清理，本波结束 | 复盘：哪门炮快没了 |

**无时间限制**：一波敌人清空即进入下一波，没有「30–45 秒波次时长」的硬框。

### 玩家动词（只有 3 个）

| 动词 | 阶段 | 频率 | 说明 |
|------|------|------|------|
| **装配** | 波次间（REFIT） | 每次危机 1 次 | 换炮塔类型、装装备 —— 本作主玩法，高注意力 |
| **接管** | 战斗（BATTLE） | 每波 0–3 次 | 切到某炮塔手动射击提速；同时只控一个 |
| **扫视** | 战斗（BATTLE） | 低频 | 切副炮视角 / 看雷达，判断哪面压力大了去接管 |

> 战斗阶段没有「指派」「下令」「资源管理」「走位」。手动接管是**可选的效率提升**，不是必须操作。

## 攻陷链（失败路径）· DEC-031 / DEC-037

```
敌人分头攻击各炮塔（主炮 + 各面副炮，每面可多门）
        │
        ├─ 某炮塔仍有耐久 → 打该炮塔耐久（自动满血进战，战中可被摧毁）
        │        └─ 该炮塔耐久归零 → 该面 / 该组失守
        │
        └─ 全部炮塔耐久归零 → 本局失败（无 Hull / 无自救）
```

**顺序**：所有炮塔逐个被毁（每毁一座该面/组失守）→ 全部归零 = 败。
**主炮通常最后沦陷**：其耐久（150–250）远高于副炮（60–100/门）、火力又最强，数值上敌人往往先清掉薄弱的副炮，最后才啃主炮。这是数值自然结果，非硬编码规则。

| 层 | 说明 | 重置 |
|----|------|------|
| 副炮耐久（60–100/门） | 被打穿则该面失守 | 每波进入战斗自动满血 |
| 主炮耐久（150–250） | 火力最强、血最厚，通常最后被盯上 | 每波进入战斗自动满血 |

**设计后果**：不接管 → 自动火力慢 → 炮塔耐久掉得快 → 面更快失守 → 整体更快崩。**代价体现在「能扛几波」，不是立即死亡**，与「装配应对战斗」主轴一致。

**失败可归因**：「我上翼副炮没及时接管被点掉了，最后主炮也扛不住了」。

## 玩家决策点地图

| 决策 | 阶段 | 频率 | 代价 | 反馈 |
|------|------|------|------|------|
| 哪面去接管 | 战斗 | 每波 0–3 次 | 同时只控一个，别的面靠自动 | 该面压力条下降 |
| 何时切视角 | 战斗 | 低频 | 切走就看不到正面舷窗 | 副炮视角画面 |
| **换哪种炮塔** | 装配 | 每次危机 1 次 | 槽位有限 | 属性面板变化 |
| **扩展槽位** | 装配 | 随进度 | — | 可装更多 |
| **预判下一波** | 装配 | 每次危机 1 次 | 预判错就挨打 | 战中验证 |

### 设计目标

> **「战斗中的手指是闲的，装配时的脑子是满的。」**

战斗阶段允许发呆（刻意）。但如果**装配阶段也让人发呆**，游戏就失败了。验证指标中「装配停留时长」正是为了盯住这一点（见 `EXPERIENCE.md`）。

**判据（DEC-021）**：随机装配的玩家 vs 认真装配的玩家，撑过的危机数应明显不同；否则「决策无意义」= 设计失败。
