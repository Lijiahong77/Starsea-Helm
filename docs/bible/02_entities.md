## 一、扇区（Sector）

飞船周围空间的静态防御分区。六面中 **aft 为推进器高温区，敌人不主攻**（DEC-036）。

| ID | 名称 | 常驻防御 | 舷窗可见 | 备注 |
|----|------|---------|---------|------|
| `fore` | 前 | **主炮**（固定） | ✅ | **唯一肉眼可见的战场**；主炮永不移动只打此面 |
| `aft` | 后 | 无 | ❌ | 推进器高温区，敌人目标分布中基本不含此面 |
| `port` | 左舷 | 副炮（可多门） | ❌ | 玩家可切视角接管 |
| `starboard` | 右舷 | 副炮（可多门） | ❌ | 玩家可切视角接管 |
| `dorsal` | 上极 | 副炮（可多门） | ❌ | 玩家可切视角接管 |
| `ventral` | 下极 | 副炮（可多门） | ❌ | 玩家可切视角接管 |

**属性**：

| 字段 | 说明 |
|------|------|
| `id` | 见上表 |
| `threat_count` | 本扇区当前敌人数 |
| `pressure` | 归一化威胁压力 0–1（威胁值 / 剩余防御力算出） |
| `sub_turrets` | 本扇区副炮数组（可为空 = 该面无防御） |
| `breached` | 是否失守（所有副炮耐久归零） |

> 上一版「六扇区五防御点、前后双缺口、主炮机动」已废止（DEC-030/036）。改为：主炮固定前、副炮四向可多门、aft 无炮。

## 二、炮塔（Turret）

可被攻击、可被摧毁、可被**装配替换**的实体。本作的「塔」。

### 2.1 主炮（Main Gun）· 固定正面

| 字段 | 值 | 说明 |
|------|-----|------|
| 位置 | `fore`，**固定不移动** | 永远只打正面 |
| 数量 | 1 组（可多门叠加） | 越强越能打 |
| 弹丸 | **离散飞行弹丸**（150–250 m/s） | 手动瞄准需 `LeadPrediction` 提前量预测 |
| 模式 | **自动 / 手动 两态** | 自动 = 间歇系统瞄准扣血；手动 = 玩家在主控室即操控主炮、按扳机发射（DEC-034） |
| 自动射击 | 慢、间歇、系统瞄准 | 守正面，「拖住」用 |
| 手动接管 | 默认在主控室即操控主炮 | 接管后提速（DEC-030） |
| 耐久 | 150 – 250 | 火力最强、血最厚，通常最后沦陷；归零 = 全部炮塔之一被毁 |

### 2.2 副炮（Sub Turret）· 四向可多门

| 字段 | 值 | 说明 |
|------|-----|------|
| 位置 | `port` / `starboard` / `dorsal` / `ventral` | 每面可叠加多门 |
| 数量 | 每面 0–N（由槽位与装配决定） | 多门聚合火力 |
| 弹丸 | **离散弹丸（一颗颗子弹，非持续光束）** | 主炮副炮皆同 |
| 模式 | **自动 / 手动 两态** | 自动 = 按 `fire_interval`（约 3s）间歇系统瞄准扣血；手动 = 玩家切到该炮视角、自己按扳机发射（DEC-034） |
| 自动射击 | 慢、间歇、系统瞄准 | 守本扇区，「拖住」用 |
| 手动接管 | 点 feed / 按 1–5 切到该副炮视角，自己开火 | 接管后提速（DEC-030） |
| 耐久 | 60 – 100 / 门 | 全灭 = 该面失守 |

**状态流转**：
```
online ──(hp ≤ 0 于本危机战中)──► destroyed（本危机内该面失守）
   └──(下一危机进入战斗)──► 自动满血复位（DEC-029：无修复经济）
```

> **已删除字段**：`can_hit_weakpoint`（弱点删除 DEC-015）、`energy_cost`（能源搁置）、`turn_delay`（主炮不再机动 DEC-030）、`overheat_*`（过热冷却已取消，用户 9/1 意见）。

## 三、炮塔类型（TurretType）· 成长核心

装配阶段在槽位上安装**不同类型/级/功能**的炮塔（DEC-033 自动解锁）。

| 类型 ID | 定位 | 典型特征 |
|---------|------|---------|
| `type_rapid` | 速射 | 高射速、低单发 |
| `type_heavy` | 重炮 | 低射速、高单发、高耐久 |
| `type_spread` | 散射 | 覆盖多目标、适合小群 |
| `type_aa` | 对空 | 专克小型战机 |
| `type_anti_armor` | 对重甲 | 高穿甲、克重甲 |
| `type_aoe` | 范围 | 溅射、清场 |

**解锁层级（随危机进度自动解锁，无货币）**：

| tier | 解锁时机 | 示例 |
|------|---------|------|
| 基础件 | 开局 | 标准副炮 ×4 + 标准主炮 |
| 进阶件 | 度过 3–5 危机 | 速射 / 重炮 / 散射 |
| 特种件 | 度过更多危机 | 对空 / 对重甲 / 范围（强但占槽多） |

> 成长点 = 解锁更多**类/级/功能** + **扩展槽位**让同面叠更多炮（取代旧「填洞」式近防炮）。

## 四、敌人（Enemy）

| ID | 名称 | 定位 | 优先级 | 备注 |
|----|------|------|--------|------|
| `enemy_interceptor` | 小型战机 | 快速、脆、数量多 | P0 | 制造持续压力 |
| `enemy_bomber` | 中型轰炸机 | 慢、厚、对炮塔伤害高 | P0 | 主要破防威胁 |
| `enemy_heavy` | 重甲单位 | 极厚、推进慢 | P1 | 考验火力总量 |

**通用属性**：

| 字段 | 说明 |
|------|------|
| `hp` | 生命值 |
| `speed` | 移动速度（刻意偏慢，见 DEC-025） |
| `turret_dps` | **对炮塔造成的持续伤害**（进入攻击距离后） |
| `sector` | 当前所属扇区（动态） |
| `armor` | 减伤（P1） |

**行为模型（Prototype 简化）**：
```
生成于扇区外缘 → 直线飞向飞船 → 进入攻击距离 → 攻击最近的玩家炮塔耐久
                → 该炮塔被毁 → 转向下一个最近炮塔
                → 所有炮塔耐久归零 → 玩家失败
```
（敌人不必"先打副炮再打主炮"——主炮只是血厚，往往最后才被清掉；这是数值结果，不是硬编码行为）

> **已删除**：`weakpoint`（弱点机制 DEC-015）、`scrap_value` / `is_bounty`（经济与悬赏取消 DEC-033）。
> 敌人类型化进攻偏好（围攻/游击/集中打主炮）为 MVP 后内容（Q12），Prototype 用随机/均匀来袭。

## 五、飞船（Ship）

全局唯一，静止。

| 字段 | 说明 |
|------|------|
| `turrets` | 主炮 + 各面副炮引用及状态 |
| `module_slots` | 模块/炮塔槽位（随进度扩展） |
| `unlocked_turret_types` | 已随危机进度解锁的炮塔类型池 |
| `equipped_loadout` | 当前装配方案（哪面装什么炮、几门） |

> **已删除**：`hull` / `hull_max`（舰桥核心取消 DEC-031）、`scrap`（经济取消 DEC-033）、`shield`（护盾 Q1 已消解）、`energy_*`（能源搁置）。

## 六、监控（Monitor）

不是单纯实体，是**主控室常驻的副炮实时画面（SubViewport 渲染）+ 接管时切主视角**（DEC-032 / DEC-038 / DEC-039）。

| 形态 | 说明 | 状态 |
|------|------|------|
| **常驻实时画面（主形态）** | 控制台常驻 4 块副炮实时画面（低清低帧 feed），扫视即知哪面有压力 | **Prototype 实现** |
| 接管切主视角 | 手动接管某副炮时主相机切到该炮，精确射击；松开回主控室 | Prototype 实现 |
| 2D 雷达总览（可选） | 纯 2D UI 画各面压力概览 | 可选，非必需 |

**性能**：4 路常驻 feed 是真实多视口开销（非「切相机零成本」），统一压到 320×180~512×288、8–12 fps（DEC-039）。

**不做**：六面全息态势图（被常驻 feed 取代，DEC-032）。
